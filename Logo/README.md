# Logo

Brand assets for SatLITE AI.

| File | Description |
|---|---|
| `logo.jpg` | Main site logo shown in the header on every page |
| `icon.jpg` | App favicon — auto-detected by Next.js when placed in `app/` |

```bash
git add Logo/
git commit -m 'assets: update brand logo and app icon'
```
